# 🚀 Dania Tech Corner

**Explore. Learn. Build.**

Uma plataforma web moderna de curadoria tecnológica, descoberta de ferramentas, inteligência artificial e recursos educativos. Desenvolvida para ser um portfólio vivo e um espaço de compartilhamento de conhecimento.

## 🛠️ Tecnologias Utilizadas
- **Next.js** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **React**
- **Lucide Icons**
- Base inicial gerada com **v0**

## 🗺️ Roadmap do Projeto

### ✅ Fase 1: Fundação e Homepage (Concluído)
- [x] Homepage responsiva com identidade visual Dania Tech Corner.
- [x] Tema Claro/Escuro/Sistema, com preferência salva no navegador.
- [x] Busca simples no catálogo, filtrando enquanto digita.
- [x] Seis cartões de categoria e uma seleção inicial de ferramentas.
- [x] Navegação por seções da própria página, menu mobile e rodapé.
- [x] Estrutura Next.js com TypeScript, Tailwind CSS e componentes React reutilizáveis.
- [x] Metadados básicos de SEO e verificação de TypeScript e dos fluxos de tema e busca.

### ⏳ Próximas Fases: Expansão do Catálogo e Páginas Internas
- [ ] **Catálogo Completo:** Incluir as 23 entradas do inventário original, revisar classificações e status (atualmente há 12 ferramentas).
- [ ] **Páginas de Exploração:** Diretório dedicado, páginas de categorias e páginas individuais das ferramentas, com links e navegação reais.
- [ ] **Filtros e Ordenação:** Filtros por categoria, preço e status editorial, além de ordenação por nome e data.
- [ ] **Conteúdo Editorial:** Seção de guias em destaque e páginas de guias.
- [ ] **Busca Avançada:** Buscar no catálogo inteiro e oferecer uma experiência própria de resultados.
- [ ] **Polimento Técnico:** Aplicar tipografia definida no briefing, revisar acessibilidade, SEO e comportamentos em desktop/mobile.

### 🚀 Visão de Futuro (Fora do escopo inicial)
- [ ] Internacionalização (i18n) e rotas por idioma (PT, IT, EN).
- [ ] Banco de dados (Supabase) e autenticação.
- [ ] Painel administrativo e CMS.
